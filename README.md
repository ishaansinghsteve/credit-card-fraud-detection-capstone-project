Credit Card Fraud Detection – Business Analysis Capstone Project

Prepared By: Ishaan Singh

Project Overview:

This Business Analytics project focuses on analysing historical credit card transaction and location data to identify potential fraud patterns and understand transaction behaviour across categories, customer demographics, and geographical regions. Using Microsoft Excel, MySQL, and Power BI, the project applies data exploration, descriptive analysis, SQL querying, and interactive visualisation to generate actionable business insights and support data-driven fraud risk assessment.

Project Components

1. Business Requirements Document (BRD): Defines the project background, business objectives, scope, stakeholders, requirements, constraints, and cost-benefit analysis.

2. Excel Analysis: Covers data exploration, descriptive statistics, transaction amount distribution, fraud analysis by gender and category, and state-level transaction summaries.

3. SQL Analysis (MySQL): Documents data exploration, date conversion, joins, aggregations, and analysis of fraud patterns, transaction categories, customer segments, and spending behaviour.

4. Power BI Dashboard: Presents key performance indicators, geographical transaction distribution, average transaction amounts by category, fraud distribution, and interactive filters.

5. Final Insights and Recommendations (PDF): Consolidates findings from Excel, SQL, and Power BI, highlighting key observations and business recommendations.

Tools & Techniques

Tools: Microsoft Excel | MySQL | Power BI | Asana

Techniques: Data Exploration | Data Cleaning and Preparation | Descriptive Statistics | Pivot Table Analysis | SQL Queries | Data Aggregation | Joins | Correlation Analysis | Data Visualisation | Interactive Dashboards | Business Insights and Recommendations

How to Explore:

1. Start with the Business Requirements Document to understand the project objectives, business problem, scope, and expected deliverables.

2. Review the Excel Analysis to explore descriptive statistics, transaction patterns, fraud distribution, and geographical summaries.

3. Examine the SQL Analysis to understand the queries, data preparation, joins, and analytical findings.

4. Explore the Power BI Dashboard to review the visual analysis and interact with the available filters.

5. Finish with the Final Insights and Recommendations report for a consolidated view of the findings and their business implications.

Note: This project presents a retrospective analysis of historical transaction data. It focuses on identifying patterns and potential fraud indicators; it does not implement a real-time fraud detection system, automated fraud prevention, or a predictive machine-learning model.
